# Student Management - Java MVC + JDBC + MySQL

## Requirements
Java 17+, Maven, MySQL 8+, Apache Tomcat 10.1+.

## Setup
1. Run database.sql in MySQL.
2. Open `src/main/java/com/example/util/DBConnection.java` and set your MySQL password.
3. Run `mvn clean package`.
4. Deploy `target/student-management.war` to Tomcat 10.1+.
5. Open `http://localhost:8080/student-management/`.

## Technologies
Java, Servlet/JSP, MVC, JDBC, MySQL, Maven, HTML, CSS, JavaScript.
